# Changelog

## 1.0.0

- Integrate optional MemoryPatrol recall and successful-stage remember through
  closed Patrol Protocol 1.0 argv, without persisting memory in run state.

- Audit ContextPatrol stage profiles and fixed request budgets, with safe generated-artifact seed exclusion.
- Bind routing/resolution/history to full authoring content identities, including skill-only changes.
- Refresh context and artifact seeds before every stage while caching immutable agent resolutions.
- Keep reviewer quality feedback unknown rather than learning approval bias.
- Settle RPC timeout/overflow despite escaped descendants retaining inherited pipes.
- Rotate telemetry through owned random exclusive files with symlink checks.
- Enforce aggregate plan/state budgets, bounded route alternatives and ContextPatrol input parity.

- Adopt Patrol Protocol 1.0 catalog/resolve/context/executor contracts with strict schemas and digests.
- Provide plan, run, approve and telemetry summary commands.
- Add explainable stage-eligible persona routing and multi-profile composition from task and stack signals.
- Add bounded adaptive scoring partitioned by task class, stage, persona, profiles, context profile and catalog digest.
- Require an explicitly trusted executor and objective verification for execution; plan needs neither.
- Preserve all seven stage gates in detached worktrees with post-build context refresh.
- Persist fresh v1 state atomically under exclusive locks; never automatically retry executor writes.
- Require separate operator approval after Ship without automatic publication, push or deployment.
- Add opt-out, allowlisted, failure-tolerant telemetry with real optional usage and route summary.
- Export the ESM library and TypeScript declarations; test isolated fixtures and packed/installed CLI execution.

There is no prior public version, migration path, legacy runtime, or compatibility mode.
